# Assets

Brand assets served by the Tabl 16 app.

## `sgorio-logo.png`

The Sgorio wordmark — **black on a transparent background, high-resolution**.

It appears in the white block at the top-left of the header (on-screen)
and in both PNG exports. The app references it at
`assets/sgorio-logo.png` (relative to `docs/index.html`), so drop the
file in this folder with exactly that name and it appears automatically
— no code changes needed.
